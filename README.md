# Íslenska — самоучитель исландского с нуля

Веб-приложение: 21 урок, словарь с озвучкой, карточки, игры, чипси, достижения и лавка.

## Как выложить на GitHub Pages

1. Создай на GitHub новый **публичный** репозиторий, например `islenska`.
2. Загрузи в него **всё содержимое этой папки** (не саму папку): `index.html`, `sw.js`, `manifest.webmanifest`, папки `icons` и `audio`.
   Проще всего: на странице репозитория **Add file → Upload files**, перетащи файлы и папки, нажми **Commit changes**.
3. Открой **Settings → Pages**. В разделе *Build and deployment* выбери **Source: Deploy from a branch**, ветку **main**, папку **/ (root)** и нажми **Save**.
4. Через 1–2 минуты приложение будет доступно по адресу `https://ИМЯ.github.io/islenska/`.

## Как установить на айфон или айпад

1. Открой ссылку **в Safari**.
2. Нажми **Поделиться → На экран «Домой» → Добавить**.
3. Заниматься **только с иконки** на экране «Домой».

Важно: у иконки и у вкладки Safari прогресс хранится раздельно. Иконка надёжнее —
айфон не удаляет данные приложений с экрана «Домой».

При первом запуске приложение скачивает всю озвучку (около 11 МБ), дальше работает и без интернета.

## Как установить на Mac

Открой ссылку в Safari и выбери **Файл → Добавить в Dock** (или в Chrome: значок установки в адресной строке).

## Сохранение прогресса

Меню → **Сохранить прогресс**:
- на айфоне и айпаде откроется меню «Поделиться» → выбери **Сохранить в Файлы** → iCloud Drive;
- на Mac файл скачается в «Загрузки» — его можно перенести в iCloud Drive.

Меню → **Восстановить прогресс** → выбрать этот файл. Приложение напоминает о сохранении, если его не было больше 2 дней.

## Как обновить приложение

Загрузи новые файлы поверх старых (Upload files → Commit). Прогресс пользователей при этом не теряется:
он хранится на их устройствах, а не на GitHub. Новая версия подхватится при следующем открытии
(иногда нужно открыть приложение два раза).
